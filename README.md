**YASSE Learn** is a production-grade, free educational web platform designed for students from Class 3 to Class 12 and verified educators. It features gamified learning, GitHub-style activity contribution streak tracking, AI video verification, direct teacher doubt clarification, and a ChatGPT AI study tutor.

Repository Link: [https://github.com/yati1818/YASSE-LEARN](https://github.com/yati1818/YASSE-LEARN)

---

## 🌟 Key Features

### 1. 🎓 Class 3 to Class 12 Adaptive Learning
- Custom tailored learning experiences for Junior (Class 3–5), Middle (Class 6–8), and Senior (Class 9–12) grade bands.
- Video lectures, instant transcripts, AI-generated lesson notes, and interactive quizzes.

### 2. 🔥 GitHub-Style Activity Contribution Heatmap
- A 35-tile contribution grid tracking daily video watch logs and quiz completions with green/orange intensity levels.
- Real-time zero baseline initialization (**0 Days, 0 Brain Synapses, 0 XP**) for new sessions.

### 3. 🤖 ChatGPT AI Study Tutor (Male & Female Personas)
- Switch between **👨‍🏫 Prof. Aryan (Male AI Mentor)** and **👩‍🏫 Dr. Ananya (Female AI Mentor)**.
- Free-form conversational ChatGPT AI that answers open-ended questions in Physics, Chemistry, Mathematics, and General Knowledge.

### 4. 📬 Email-Only Developer Video Approval Token System
- Teacher video uploads are dispatched to developer email: **`yatishsathish3012@gmail.com`**.
- Direct GET token link inside Gmail inbox approves videos without on-site admin banners.

### 5. 🛡️ Creator OTP & Teacher Mobile Verification
- Automated OTP dispatch for video uploads.
- 10-digit mobile verification for teachers kept 100% private.

## 🚀 Quick Start & Local Run

### Prerequisites
- Node.js v18.0.0 or higher
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/yati1818/YASSE-LEARN.git

# Navigate into project directory
cd YASSE-LEARN

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application live!

## 🌐 Live Web Deployment Setup

To deploy this project live for public access:

### Deploy via Vercel (Recommended)
1. Push this repository to GitHub (`https://github.com/yati1818/YASSE-LEARN`).
2. Visit [Vercel.com](https://vercel.com) and click **"New Project"**.
3. Import the `yati1818/YASSE-LEARN` repository.
4. Click **Deploy**. Vercel will build and provide a live public URL (e.g. `https://yasse-learn.vercel.app`).
